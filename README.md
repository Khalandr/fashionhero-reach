# FashionHero Reach — sponsored placement smoke test

Smoke-test landing page for **FashionHero Reach** — a productized sponsored-listings + Etsy-style Offsite Ads service for sellers on FashionHero (fictional Polish fashion marketplace, used as the AIPH2 case study).

Built as **quest 3.2 (Smoke & Mirrors)** in the [AI Product Heroes](https://questlog.aiproductheroes.pl/) course — the prototype tests **AT-1** from the Q2.4 Opportunity Solution Tree: *sellers opt-in to higher-take-rate Offsite Ads if attribution is clear* (transparent 16-180n paid-traffic-attributed sales vs 22ase commission).

**Live:** https://khalandr.github.io/fashionhero-reach/

## Why this prototype
Built on the convergence of 5 independent sources from the AIPH2 Q2.x discovery sprint:
- **Quant** — 500-seller CSV (Q2.1): marketing_spend coefficient on net margin ~0; 80% of sellers can't attribute ROI.
- **Qual** — seller interviews (Q2.2): "musi działać, ale ciężko mi powiedzieć" (Bartek).
- **Competitive** — Etsy Offsite Ads precedent: 6.5% → 13% blended take rate without raising base commission.
- **Industry** — Bain marketplace report 2023: 30-40% non-commission revenue is standard for mature platforms.
- **Academic** — Rochet & Tirole 2003: continuous pricing per side elasticity is theoretically optimal.

## Success / kill thresholds (per Q2.4 OST)
- **Success:** ≥ 15% email conversion (75 emails per 500 impressions).
- **Kill:** < 5%.
- **Iterate:** 5-15% — refine value prop / pricing anchor / proof.
